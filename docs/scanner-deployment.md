# Scanner workload contract

Production scanning is an isolated, operator-supplied **ClamAV-compatible scanner facade**. The API sends a bounded raw payload to `POST SCANNER_ENDPOINT` with `content-type: application/octet-stream`, `x-lexilens-declared-mime`, and `x-lexilens-scanner-version`. It accepts only JSON `{ "verdict": "clean", "detectedMime": "text/plain", "scannerVersion": "<configured version>" }`. A malicious verdict is rejected; malformed responses, version mismatch, non-2xx responses, timeouts, and network errors fail closed.

The Terraform template provisions only the workload boundary: it configures an isolated scanner ECS task on port 443 and limits scanner security-group ingress to API and scheduled worker tasks. It does not create service discovery, a load balancer, TLS certificates, or DNS for that endpoint; the private scanner route must be connected in a separately reviewed ingress/service-discovery module. The scanner image, immutable digest, vulnerability review, ClamAV definition-update strategy, and approved facade implementation must be supplied by the deployment operator. No vendor, credentials, scanner image, or live scanner is bundled or provisioned here.

Do not enable PDF/image uploads in production until a separately reviewed sandboxed parser/OCR pipeline is deployed. The API and worker receive the AWS-managed RDS secret as separately injected host, port, username, password, and database-name values; the application constructs and validates its PostgreSQL URL at startup. Scanner endpoint/version and OIDC configuration are injected as Secrets Manager values rather than baked into an image.
