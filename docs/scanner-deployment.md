# Scanner workload contract

Production scanning is an isolated, operator-supplied **ClamAV-compatible scanner facade**. The API sends a bounded raw payload to `POST SCANNER_ENDPOINT` with `content-type: application/octet-stream`, `x-lexilens-declared-mime`, and `x-lexilens-scanner-version`. It accepts only JSON `{ "verdict": "clean", "detectedMime": "text/plain", "scannerVersion": "<configured version>" }`. A malicious verdict is rejected; malformed responses, version mismatch, non-2xx responses, timeouts, and network errors fail closed.

Terraform routes this endpoint privately. It creates an internal HTTPS scanner ALB, TLS listener using the required scanner ACM certificate, HTTPS target group and health check, and a required private Route 53 alias record. The API and maintenance worker can reach the scanner ALB on 443; the scanner task itself accepts 443 only from that ALB and has no public IP. Terraform injects `SCANNER_ENDPOINT` as `https://<scanner_private_dns_name>/scan` from the Route 53 record—not an unrelated operator endpoint—so the API configured-scanner mode resolves to the deployed scanner service. The operator must supply an immutable approved facade image, a certificate trusted by API/worker tasks, the private hosted-zone/DNS inputs, and a facade whose `/health` and `/scan` routes match this contract.

Do not enable PDF/image uploads in production until a separately reviewed sandboxed parser/OCR pipeline is deployed. The API and worker receive the AWS-managed RDS secret as separately injected host, port, username, password, and database-name values; the application constructs and validates its PostgreSQL URL at startup. Scanner endpoint/version and OIDC configuration are injected as Secrets Manager values rather than baked into an image. No vendor, credentials, scanner image, or live scanner is bundled or provisioned here.
